CLI

Terminal power.

8 commands. Rich output. Pipe support. CI threshold mode. Works anywhere Python runs.

Install

# Activate venv first venv\Scripts\activate # Windows source venv/bin/activate # Mac/Linux # Install CLI pip install -e . # Verify sloplens --version sloplens doctor

After install, set backend URL once:

sloplens config --backend http://localhost:8000

scan — Score any text

Scan text directly, from a file, or from a URL.

Text
sloplens scan "Moving forward we will leverage synergies"
File
sloplens scan --file README.md
URL
sloplens scan --url https://example.com/blog-post
CI Mode
sloplens scan --file README.md --threshold 60
Pipe
cat README.md | sloplens scan
JSON
sloplens scan --file docs.md --json

ⓘ CI mode exits with code 1 if slop score > threshold — use in GitHub Actions or pre-push hooks.

repo — Scan a GitHub repo

Scans README, last 20 PRs, and last 30 commits in parallel.

By name
sloplens repo microsoft/vscode
By URL
sloplens repo https://github.com/torvalds/linux
JSON
sloplens repo openai/openai-python --json

compare — Before vs after

Compare two files. Shows score delta, time saved, signal gained.

Compare
sloplens compare before.md after.md
JSON
sloplens compare v1.txt v2.txt --json

condense — Remove fluff

Rewrites text using LLM, removing all slop.

Text
sloplens condense "In today's fast-paced world..."
File
sloplens condense --file bloated.md
Save
sloplens condense --file bloated.md --output clean.md
Pipe
cat bloated.md | sloplens condense

batch — Rank multiple files

Scans multiple files and ranks by slop score.

All MD
sloplens batch docs/*.md
Threshold
sloplens batch *.txt --threshold 70

ⓘ With --threshold, exits code 1 if any file exceeds it — good for CI batch checks.

init — Setup repo

One command installs pre-commit hook and GitHub Action in current repo.

Setup
sloplens init
Threshold
sloplens init --threshold 65

config — Settings

Set URL
sloplens config --backend http://localhost:8000
Show
sloplens config --show
Reset
sloplens config --reset

doctor — Health check

Checks backend connection and API key status.

Check
sloplens doctor

# .github/workflows/slop-check.yml - name: Check docs for slop run: | pip install -e . sloplens config --backend ${{ "{{" }} secrets.SLOPLENS_URL }} sloplens batch docs/*.md --threshold 70
