Chrome Extension

Install SlopLens.

Score any webpage instantly. Heatmap overlay. Auto-scan. Works on every site.

Step 1 — Set Backend URL

Open extension/config.js in your project folder and set your backend URL:

// extension/config.js const SLOPLENS_BACKEND = "https://sloplens.onrender.com";

⚠ Backend is live at https://sloplens.onrender.com — no local setup needed.

Step 2 — Load in Chrome

1

Open Extensions page

Type chrome://extensions in Chrome address bar and press Enter.

2

Enable Developer Mode

Toggle the Developer Mode switch in the top-right corner of the extensions page. It must be ON (blue).

3

Load Unpacked

Click the Load unpacked button that appears. Navigate to your project folder and select the extension/ folder. Click OK.

4

SlopLens appears

SlopLens will appear in your extensions list with its icon. It is now active on all websites.

Step 3 — Using the Extension

🔍

Badge on every page

Visit any webpage. A SlopLens badge appears in the bottom-right corner. Click it to scan the page.

📊

Detail panel

After scanning, click the score badge again. A panel opens showing score, reading time vs useful time, roast, flagged phrases, and fix.

🌟

Heatmap overlay

Inside the panel, click Show Heatmap. Green/yellow/red backgrounds appear on page elements — green = useful, yellow = filler, red = slop.

⚙

Auto-scan (optional)

Click the SlopLens extension icon in Chrome toolbar → toggle Auto-scan on page load. Every page you visit gets scored automatically.

Troubleshooting

Common issues
Badge not showing
Reload the extension: chrome://extensions → SlopLens → ↻ Reload button
Error — retry
Backend not running. Open terminal and run: python run.py
Heatmap not working
Try on Wikipedia: en.wikipedia.org — some sites block background changes via CSP.
Backend URL
Backend is already set to https://sloplens.onrender.com in config.js — no changes needed.
