Endpoints

POST /scan Full 3-layer hybrid scan

Scores text using all three layers: heuristic + sentence-transformers + Groq LLM.

// Request { "text": "In today's fast-paced world...", "fast": false // true = faster, slightly less accurate } // Response { "overall_slop_score": 78, "information_density": 22, "filler_ratio": 85, "specificity": 18, "naturalness": 30, "reading_time_min": 2.1, "info_time_min": 0.4, "fluff_percent": 79, "roast": "80 words saying absolutely nothing.", "verdict": "Pure jargon dressed as strategy.", "flagged_phrases": ["moving forward", "best-in-class"], "fix": "Replace vague phrases with specific actions.", "confidence_interval": 6, "slop_category": "corporate_buzzwords" }
POST /scan/compare Compare two texts

Scores both texts in parallel. Returns improvement delta, time saved, signal gained.

// Request { "text_a": "Before version...", "text_b": "After version...", "fast": false } // Response { "before": { ...full scan result... }, "after": { ...full scan result... }, "improvement": 47, "time_saved": 1.8, "signal_gained": 0.9, "summary": "Slop cut by 47 pts · 1.8min saved" }
POST /scan/repo Scan a GitHub repo

Scans README + last 20 PRs + last 30 commits in parallel. No token needed for public repos.

// Request { "repo": "microsoft/vscode", "fast": true } // Response { "repo": "microsoft/vscode", "overall_slop_score": 34, "sections": [ { "section": "README", "slop_score": 28, "word_count": 1240 }, { "section": "PR Descriptions", "slop_score": 41, "pr_count": 20, "score_distribution": { "clean": 12, "medium": 6, "slop": 2 } }, { "section": "Commit Messages", "slop_score": 33, "commit_count": 30 } ], "cleanest_section": "README", "sloppiest_section": "PR Descriptions" }
POST /scan/condense Rewrite text removing slop

Uses Groq LLM to rewrite text, cutting all filler, buzzwords, and passive voice.

// Request { "text": "In today's fast-paced world..." } // Response { "original": "...", "condensed": "...", "words_before": 120, "words_after": 48, "words_cut": 72, "percent_cut": 60, "slop_before": 81, "slop_after": 22, "time_saved": 0.3 }
POST /scan/urls Fetch and rank URLs
// Request { "urls": ["https://example.com/blog", "https://docs.site.com"], "fast": true } // Response { "results": [ { "url": "...", "overall_slop_score": 72, "fluff_percent": 68 }, ... ] }
POST /scan/heuristic Free instant scan (no LLM) Free

Heuristic + semantic layers only. No Groq API call. Instant response. Good for high-volume use.

{ "text": "your text here" }
POST /scan/batch Batch scan up to 10 texts
{ "texts": ["text1", "text2", "text3"], "fast": true }
GET /badge/{owner}/{repo}.svg Live SVG badge

Returns SVG badge. Embed in README:

[![SlopLens](https://your-api.railway.app/badge/owner/repo.svg)](https://sloplens.dev)
GET /leaderboard Top 20 sloppiest repos

Returns top 20 repos by slop score. Updated on every /scan/repo call.
